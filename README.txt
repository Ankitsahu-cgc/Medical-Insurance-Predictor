# Insurance Expense Predictor

A machine learning-based web application that predicts estimated medical insurance expenses based on demographic and health-related information.

## Project Overview

The project uses a **Linear Regression** model to estimate a person's medical insurance expenses using features such as:

- Age
- Gender
- BMI
- Number of Children
- Smoking Status
- Region

The trained model's prediction logic is integrated into a simple interactive web interface built using **HTML, CSS, and JavaScript**.

## Objective

The main objective of this project is to estimate insurance-related medical expenses based on an individual's personal and health characteristics.

## Machine Learning

### Algorithm Used
- Linear Regression

### Features Used
- Age
- Sex
- BMI
- Children
- Smoker
- Region
- BMI Category

### Target Variable
- `expenses`

The model predicts the estimated medical expenses associated with the given customer information.
