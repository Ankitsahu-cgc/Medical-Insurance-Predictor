Data story

Key findings

1 · Smoking dominatesSmoker status has the strongest Pearson association with expense at 0.787, well above age (0.299) and BMI (0.198).
2 · Large smoker gapAcross the dataset, smokers average about ₹32,050 in charges versus ₹8,434 for non-smokers — almost 4×.
3 · Smoker × obesity interactionExternal EDA on the same public dataset reports about ₹41,558 for obese smokers versus ₹8,842 for obese non-smokers, showing a strong combined-cost pattern.
4 · Target is strongly skewedExpense ranges from ₹1,121.87 to ₹63,770.43; mean is ₹13,270.42 while median is ₹9,382.03.
5 · Age matters, but lessAge has a moderate positive association (0.299). Public EDA grouped the same dataset from about ₹9.2k at ages 18–29 to about ₹21.2k at 60+.
6 · Several features are weakChildren (0.068), sex (−0.057), and two regional indicators have small Pearson correlations; chi-square also rejected several categorical candidates at α=0.05.
Reproducibility

Model notes

Features used
  • age, is_female, bmi, children, is_smoker
  • region_southeast, bmi_category_Obese, region_northwest
  • age, BMI and children standardized with StandardScaler
Training setup
  • LinearRegression from scikit-learn
  • 80/20 train-test split
  • random_state = 42
  • test n = 268
Important limitation
  • The notebook does not calculate RMSE, MAE or 5-fold CV R².
  • It also does not save model.coef_, intercept_, y_test or y_pred.
  • The live predictor therefore uses a centered coefficient approximation for the same feature design; it should be replaced with the serialized trained coefficients for exact reproduction.
Data scope
  • 1,338 rows, 7 original columns, no missing values.
  • Age: 18–64; BMI: 16.0–53.1 in the notebook's displayed data summary.
  • Target: yearly medical expense / insurance charge.
Dashboard basis: uploaded Insurance_Project(1).ipynb. Notebook-derived model metrics and feature-selection values are kept separate from supplemental public-dataset EDA used to fill requested visual context. This dashboard is an analytics/education interface, not a medical or insurance-pricing recommendation.
